# Error Codes

## Function Validation Errors

| Code    | Description                                                            |
| ------- | ---------------------------------------------------------------------- |
| `50001` | A required input is null.                                              |
| `50002` | An input exceeds its allowed maximum length.                           |
| `50003` | Two related inputs must be different (e.g. card front/backside).        |
| `50004` | Referenced record does not exist (e.g. owner account id).               |
| `50005` | Authentication / active session lookup failed.                          |
| `50006` | An input value has an invalid format (e.g. session id).                 |
